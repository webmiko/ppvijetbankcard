## Когда использовать

Словари используются **всегда** для хранения данных в формате ключ-значение, работы с JSON, конфигурациями и структурированными данными.

## Создание словарей

```python
# Пустой словарь
empty = {}

# С элементами
person = {
    'name': 'Иван',
    'age': 25,
    'city': 'Москва'
}

# С помощью dict()
person = dict(name='Иван', age=25, city='Москва')

# Из списка кортежей
person = dict([('name', 'Иван'), ('age', 25)])
```

## Доступ к элементам

```python
person = {'name': 'Иван', 'age': 25}

# По ключу
name = person['name']        # 'Иван'

# get() - безопасный доступ
age = person.get('age')      # 25
email = person.get('email', 'не указан')  # 'не указан' (значение по умолчанию)

# Проверка наличия ключа
if 'name' in person:
    print(person['name'])
```

## Изменение словарей

### Добавление и изменение
```python
person = {'name': 'Иван'}

# Добавление/изменение элемента
person['age'] = 25           # {'name': 'Иван', 'age': 25}
person['name'] = 'Петр'      # {'name': 'Петр', 'age': 25}

# update() - обновление несколькими элементами
person.update({'city': 'Москва', 'age': 26})
```

### Удаление элементов
```python
person = {'name': 'Иван', 'age': 25, 'city': 'Москва'}

# del - удаление по ключу
del person['city']           # {'name': 'Иван', 'age': 25}

# pop() - удаление с возвратом значения
age = person.pop('age')      # 25, словарь: {'name': 'Иван'}

# popitem() - удаление последнего элемента
item = person.popitem()      # ('name', 'Иван')

# clear() - очистка словаря
person.clear()               # {}
```

## Итерация по словарю

```python
person = {'name': 'Иван', 'age': 25, 'city': 'Москва'}

# Ключи
for key in person:
    print(key)

# Ключи явно
for key in person.keys():
    print(key)

# Значения
for value in person.values():
    print(value)

# Ключи и значения
for key, value in person.items():
    print(f"{key}: {value}")
```

## Вложенные словари

```python
users = {
    'user1': {'name': 'Иван', 'age': 25},
    'user2': {'name': 'Петр', 'age': 30}
}

# Доступ к вложенным элементам
name = users['user1']['name']  # 'Иван'
age = users.get('user1', {}).get('age', 0)  # Безопасный доступ
```

## Методы словарей

```python
person = {'name': 'Иван', 'age': 25}

# Копирование
copy = person.copy()

# Объединение словарей (Python 3.9+)
dict1 = {'a': 1}
dict2 = {'b': 2}
merged = dict1 | dict2  # {'a': 1, 'b': 2}

# setdefault() - получить значение или установить по умолчанию
city = person.setdefault('city', 'Москва')  # 'Москва', добавляет ключ
```

## Приоритеты использования

### В первую очередь (обязательно знать)
- Создание и доступ к элементам
- Метод `get()` для безопасного доступа
- Итерация по словарю (`for key, value in dict.items()`)
- Проверка наличия ключа (`in`)

### По необходимости
- Методы `update()`, `pop()`, `popitem()`
- Вложенные словари
- Объединение словарей
- `setdefault()` для установки значений по умолчанию
