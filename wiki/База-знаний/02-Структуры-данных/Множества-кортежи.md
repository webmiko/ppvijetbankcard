## Когда использовать

- **Кортежи** - когда нужна неизменяемая упорядоченная коллекция (координаты, константы)
- **Множества** - когда нужны уникальные элементы и операции над множествами
- **Вложенные коллекции** - для сложных структур данных

## Кортежи (tuples)

### Создание кортежей
```python
# Пустой кортеж
empty = ()

# С элементами
point = (10, 20)
person = ('Иван', 25, 'Москва')

# Без скобок (кортеж из одного элемента требует запятую)
single = (5,)  # Кортеж
not_tuple = (5)  # Число

# С помощью tuple()
numbers = tuple([1, 2, 3])  # (1, 2, 3)
```

### Доступ к элементам
```python
point = (10, 20)
x = point[0]      # 10
y = point[1]      # 20

# Распаковка
x, y = point      # x=10, y=20
```

### Операции с кортежами
```python
tuple1 = (1, 2)
tuple2 = (3, 4)

# Объединение
combined = tuple1 + tuple2  # (1, 2, 3, 4)

# Повторение
repeated = tuple1 * 3       # (1, 2, 1, 2, 1, 2)

# Проверка наличия
2 in tuple1                 # True
```

## Множества (sets)

### Создание множеств
```python
# Пустое множество
empty = set()  # Нельзя использовать {} - это словарь!

# С элементами
fruits = {'яблоко', 'банан', 'апельсин'}

# Из списка (удаляет дубликаты)
numbers = set([1, 2, 2, 3, 3])  # {1, 2, 3}
```

### Операции с множествами
```python
set1 = {1, 2, 3, 4}
set2 = {3, 4, 5, 6}

# Добавление элементов
set1.add(5)           # {1, 2, 3, 4, 5}

# Удаление элементов
set1.remove(5)        # {1, 2, 3, 4}
set1.discard(10)      # Не вызывает ошибку если элемента нет

# Операции над множествами
union = set1 | set2           # {1, 2, 3, 4, 5, 6} - объединение
intersection = set1 & set2    # {3, 4} - пересечение
difference = set1 - set2      # {1, 2} - разность
symmetric = set1 ^ set2       # {1, 2, 5, 6} - симметричная разность

# Проверки
set1.issubset(set2)           # False
set1.issuperset({1, 2})       # True
```

## Вложенные коллекции

### Списки списков
```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

# Доступ к элементам
value = matrix[1][2]  # 6

# Итерация
for row in matrix:
    for cell in row:
        print(cell)
```

### Словари со списками
```python
data = {
    'names': ['Иван', 'Петр', 'Мария'],
    'ages': [25, 30, 28]
}

# Доступ
first_name = data['names'][0]  # 'Иван'
```

### Список словарей
```python
users = [
    {'name': 'Иван', 'age': 25},
    {'name': 'Петр', 'age': 30}
]

# Итерация
for user in users:
    print(f"{user['name']}: {user['age']}")
```
