## Когда использовать

Списки используются **всегда** для хранения упорядоченных коллекций данных, когда важен порядок элементов и нужен доступ по индексу.

## Создание списков

```python
# Пустой список
empty = []

# С элементами
numbers = [1, 2, 3, 4, 5]
fruits = ['яблоко', 'банан', 'апельсин']

# Смешанные типы
mixed = [1, 'строка', 3.14, True]

# С помощью list()
numbers = list(range(5))  # [0, 1, 2, 3, 4]
```

## Доступ к элементам

```python
fruits = ['яблоко', 'банан', 'апельсин']

# По индексу
first = fruits[0]      # 'яблоко'
last = fruits[-1]      # 'апельсин'

# Срезы
subset = fruits[1:3]   # ['банан', 'апельсин']
first_two = fruits[:2] # ['яблоко', 'банан']
last_two = fruits[1:]   # ['банан', 'апельсин']
```

## Изменение списков

### Добавление элементов
```python
fruits = ['яблоко', 'банан']

# append() - в конец
fruits.append('апельсин')  # ['яблоко', 'банан', 'апельсин']

# insert() - в указанную позицию
fruits.insert(1, 'груша')   # ['яблоко', 'груша', 'банан', 'апельсин']

# extend() - добавить несколько элементов
fruits.extend(['виноград', 'киви'])  # Расширяет список
```

### Удаление элементов
```python
fruits = ['яблоко', 'банан', 'апельсин']

# remove() - по значению
fruits.remove('банан')  # ['яблоко', 'апельсин']

# pop() - по индексу (возвращает элемент)
last = fruits.pop()     # 'апельсин', список: ['яблоко']
first = fruits.pop(0)  # 'яблоко', список: []

# del - удаление по индексу
del fruits[0]
```

### Изменение элементов
```python
fruits = ['яблоко', 'банан', 'апельсин']
fruits[1] = 'груша'  # ['яблоко', 'груша', 'апельсин']
```

## Операции со списками

### Поиск и проверка
```python
fruits = ['яблоко', 'банан', 'апельсин']

# Проверка наличия
'банан' in fruits     # True
'груша' not in fruits # True

# Индекс элемента
index = fruits.index('банан')  # 1

# Подсчет
count = fruits.count('яблоко')  # 1
```

### Сортировка
```python
numbers = [3, 1, 4, 1, 5]

# sort() - изменяет список
numbers.sort()        # [1, 1, 3, 4, 5]
numbers.sort(reverse=True)  # [5, 4, 3, 1, 1]

# sorted() - возвращает новый список
sorted_numbers = sorted(numbers)  # Не изменяет исходный
```

### Обращение и копирование
```python
fruits = ['яблоко', 'банан', 'апельсин']

# reverse() - обращает список
fruits.reverse()  # ['апельсин', 'банан', 'яблоко']

# Копирование
copy1 = fruits.copy()      # Поверхностная копия
copy2 = fruits[:]          # Срез всего списка
copy3 = list(fruits)       # Конструктор list()
```

## Встроенные функции

```python
numbers = [1, 2, 3, 4, 5]

len(numbers)        # 5 - длина списка
min(numbers)        # 1 - минимальный элемент
max(numbers)        # 5 - максимальный элемент
sum(numbers)        # 15 - сумма элементов
```

## Приоритеты использования

### В первую очередь (обязательно знать)
- Создание и доступ к элементам
- Методы `append()`, `remove()`, `pop()`
- Проверка наличия (`in`, `not in`)
- Итерация по списку (`for`)

### По необходимости
- Методы `insert()`, `extend()`
- Сортировка (`sort()`, `sorted()`)
- Копирование списков
- Вложенные списки
