## Когда использовать

Строки используются **всегда** при работе с текстовыми данными, вводами пользователя, обработке файлов и форматировании вывода.

## Основные операции

### Создание строк
```python
# Одинарные кавычки
text = 'Привет'

# Двойные кавычки
text = "Привет"

# Многострочные строки
text = """Первая строка
Вторая строка"""
```

### Индексация и срезы
```python
text = "Python"
print(text[0])      # P
print(text[-1])     # n
print(text[1:4])    # yth
print(text[:3])     # Pyt
print(text[3:])     # hon
```

### Основные методы
```python
text = "  Python  "

# Удаление пробелов
text.strip()        # "Python"
text.lstrip()       # "Python  "
text.rstrip()       # "  Python"

# Регистр
text.upper()        # "  PYTHON  "
text.lower()        # "  python  "
text.capitalize()   # "  python  "
text.title()        # "  Python  "

# Поиск и замена
text.find("Py")     # 2
text.replace("Py", "Ja")  # "  Javathon  "

# Разделение и объединение
"a,b,c".split(",")  # ['a', 'b', 'c']
",".join(['a', 'b', 'c'])  # "a,b,c"
```

### Форматирование строк
```python
# f-строки (рекомендуется)
name = "Иван"
age = 25
text = f"Меня зовут {name}, мне {age} лет"

# format()
text = "Меня зовут {}, мне {} лет".format(name, age)

# %
text = "Меня зовут %s, мне %d лет" % (name, age)
```

### Проверка содержимого
```python
text = "Python123"

text.isdigit()      # False
text.isalpha()      # False
text.isalnum()      # True
text.startswith("Py")  # True
text.endswith("123")   # True
```
