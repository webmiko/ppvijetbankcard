## Когда использовать

Циклы используются **всегда** для повторения операций, обработки коллекций данных и итерации по элементам.

## Цикл for

### Базовое использование
```python
# Итерация по списку
fruits = ['яблоко', 'банан', 'апельсин']
for fruit in fruits:
    print(fruit)

# Итерация по строке
for char in "Python":
    print(char)

# Итерация с индексом
for i, fruit in enumerate(fruits):
    print(f"{i}: {fruit}")
```

### Итерация по словарю
```python
data = {'name': 'Иван', 'age': 25}

# Только ключи
for key in data:
    print(key)

# Ключи и значения
for key, value in data.items():
    print(f"{key}: {value}")

# Только значения
for value in data.values():
    print(value)
```

### Диапазоны
```python
# range(stop)
for i in range(5):
    print(i)  # 0, 1, 2, 3, 4

# range(start, stop)
for i in range(2, 5):
    print(i)  # 2, 3, 4

# range(start, stop, step)
for i in range(0, 10, 2):
    print(i)  # 0, 2, 4, 6, 8
```

## Цикл while

```python
# Базовый цикл
count = 0
while count < 5:
    print(count)
    count += 1

# С условием выхода
while True:
    user_input = input("Введите 'выход' для завершения: ")
    if user_input == 'выход':
        break
```

## Управление циклами

### break - выход из цикла
```python
for i in range(10):
    if i == 5:
        break
    print(i)  # 0, 1, 2, 3, 4
```

### continue - пропуск итерации
```python
for i in range(10):
    if i % 2 == 0:
        continue
    print(i)  # 1, 3, 5, 7, 9
```

### else - выполнение после завершения цикла
```python
for i in range(5):
    print(i)
else:
    print("Цикл завершен")  # Выполнится если не было break
```

## Вложенные циклы

```python
for i in range(3):
    for j in range(3):
        print(f"{i}-{j}", end=" ")
    print()
# Вывод:
# 0-0 0-1 0-2
# 1-0 1-1 1-2
# 2-0 2-1 2-2
```

## Приоритеты использования

### В первую очередь (обязательно знать)
- Цикл `for` для итерации по коллекциям
- `range()` для числовых последовательностей
- `break` и `continue` для управления циклом

### По необходимости
- Цикл `while` для условных повторений
- Вложенные циклы для сложных структур
- `enumerate()` для получения индексов
