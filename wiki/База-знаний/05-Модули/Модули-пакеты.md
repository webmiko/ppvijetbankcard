## Когда использовать

Модули и пакеты используются **всегда** при создании проектов с несколькими файлами для организации кода и переиспользования функциональности.

## Модули

### Создание модуля
```python
# Файл: math_utils.py
def add(a, b):
    return a + b

def multiply(a, b):
    return a * b

PI = 3.14159
```

### Импорт модуля
```python
# Импорт всего модуля
import math_utils
result = math_utils.add(5, 3)

# Импорт с псевдонимом
import math_utils as mu
result = mu.add(5, 3)

# Импорт конкретных функций
from math_utils import add, multiply
result = add(5, 3)

# Импорт всего содержимого (не рекомендуется)
from math_utils import *
result = add(5, 3)
```

## Пакеты

### Структура пакета
```
my_package/
    __init__.py
    module1.py
    module2.py
    subpackage/
        __init__.py
        module3.py
```

### Создание пакета
```python
# Файл: my_package/__init__.py
from .module1 import function1
from .module2 import function2

__all__ = ['function1', 'function2']
```

### Импорт из пакета
```python
# Импорт из пакета
from my_package import function1
from my_package.module1 import function1

# Импорт из подпакета
from my_package.subpackage import module3
from my_package.subpackage.module3 import function3
```

## Стандартные модули Python

### Часто используемые модули
```python
# Математические операции
import math
math.sqrt(16)  # 4.0
math.pi        # 3.14159...

# Работа с датами и временем
from datetime import datetime, timedelta
now = datetime.now()
tomorrow = now + timedelta(days=1)

# Случайные числа
import random
random.randint(1, 10)
random.choice(['a', 'b', 'c'])

# Работа с путями
from pathlib import Path
path = Path('data/file.txt')

# Системные функции
import os
os.getcwd()  # Текущая директория
os.path.exists('file.txt')  # Проверка существования
```

## Относительный и абсолютный импорт

### Абсолютный импорт
```python
# Из корня проекта
from src.masks import get_mask_card_number
from generators.generators import filter_by_currency
```

### Относительный импорт
```python
# Внутри пакета
from .module1 import function1      # Текущий пакет
from ..parent import function2     # Родительский пакет
from .subpackage.module3 import function3  # Подпакет
```

## __init__.py

### Назначение
- Делает директорию пакетом Python
- Определяет, что импортируется при `import package`
- Может содержать инициализационный код

```python
# Файл: my_package/__init__.py
"""Описание пакета"""

# Импорт основных функций для удобства
from .module1 import main_function
from .module2 import helper_function

# Определение __all__ для from package import *
__all__ = ['main_function', 'helper_function']

# Инициализация пакета
VERSION = '1.0.0'
```

## Поиск модулей (sys.path)

```python
import sys

# Добавление пути к sys.path
sys.path.append('/path/to/modules')

# Просмотр путей поиска модулей
for path in sys.path:
    print(path)
```

## Приоритеты использования

### В первую очередь (важно знать)
- Создание модулей и их импорт
- Структура пакетов с `__init__.py`
- Импорт стандартных модулей (`math`, `datetime`, `os`)

### По необходимости
- Относительный импорт внутри пакетов
- Настройка `__all__` в `__init__.py`
- Модификация `sys.path` для нестандартных путей
