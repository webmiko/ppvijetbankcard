## Когда использовать

- **Включения (comprehensions)** - для создания коллекций из других коллекций (когда нужен список/словарь/множество)
- **Генераторы** - для работы с большими объемами данных без загрузки всего в память

## List Comprehension (Включения списков)

### Базовый синтаксис
```python
# Обычный способ
squares = []
for x in range(10):
    squares.append(x ** 2)

# С включением
squares = [x ** 2 for x in range(10)]  # [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]
```

### С условием
```python
# Только четные числа
evens = [x for x in range(10) if x % 2 == 0]  # [0, 2, 4, 6, 8]

# С условием в выражении
result = [x if x % 2 == 0 else x * 2 for x in range(5)]  # [0, 2, 2, 6, 4]
```

### Вложенные циклы
```python
# Декартово произведение
pairs = [(x, y) for x in [1, 2] for y in [3, 4]]
# [(1, 3), (1, 4), (2, 3), (2, 4)]

# Плоское представление вложенного списка
matrix = [[1, 2], [3, 4], [5, 6]]
flat = [num for row in matrix for num in row]  # [1, 2, 3, 4, 5, 6]
```

## Dict Comprehension (Включения словарей)

```python
# Создание словаря из списка
numbers = [1, 2, 3, 4]
squares_dict = {x: x ** 2 for x in numbers}  # {1: 1, 2: 4, 3: 9, 4: 16}

# С условием
evens_dict = {x: x ** 2 for x in numbers if x % 2 == 0}  # {2: 4, 4: 16}

# Из другого словаря
original = {'a': 1, 'b': 2, 'c': 3}
doubled = {k: v * 2 for k, v in original.items()}  # {'a': 2, 'b': 4, 'c': 6}
```

## Set Comprehension (Включения множеств)

```python
# Создание множества
squares_set = {x ** 2 for x in range(5)}  # {0, 1, 4, 9, 16}

# Удаление дубликатов
words = ['hello', 'world', 'hello']
unique_lengths = {len(word) for word in words}  # {5, 5} -> {5}
```

## Генераторы (Generator Expressions)

### Базовый синтаксис
```python
# Генератор (ленивое вычисление)
squares_gen = (x ** 2 for x in range(10))

# Использование
for square in squares_gen:
    print(square)

# Преобразование в список (если нужно)
squares_list = list(squares_gen)
```

### Функции-генераторы
```python
def squares(n):
    """Генератор квадратов чисел от 0 до n"""
    for i in range(n):
        yield i ** 2

# Использование
for square in squares(5):
    print(square)  # 0, 1, 4, 9, 16

# Получение следующего значения
gen = squares(5)
print(next(gen))  # 0
print(next(gen))  # 1
```

### Генераторы с условиями
```python
def even_numbers(n):
    """Генератор четных чисел"""
    for i in range(n):
        if i % 2 == 0:
            yield i

# Или с включением
evens = (x for x in range(10) if x % 2 == 0)
```

## Преимущества генераторов

### Экономия памяти
```python
# Список - загружает все в память
squares_list = [x ** 2 for x in range(1000000)]  # Занимает много памяти

# Генератор - вычисляет по требованию
squares_gen = (x ** 2 for x in range(1000000))  # Экономит память
```

### Ленивое вычисление
```python
def read_large_file(filename):
    """Читает большой файл построчно без загрузки всего в память"""
    with open(filename, 'r') as f:
        for line in f:
            yield line.strip()

# Обработка файла построчно
for line in read_large_file('large_file.txt'):
    process(line)
```

## Приоритеты использования

### В первую очередь (важно знать)
- List comprehension для создания списков
- Dict comprehension для создания словарей
- Базовые генераторы для экономии памяти

### По необходимости
- Set comprehension
- Функции-генераторы с `yield`
- Генераторы для работы с большими файлами
- `next()` для ручного управления генераторами
