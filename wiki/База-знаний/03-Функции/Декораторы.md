## Когда использовать

Декораторы используются для расширения функциональности функций без изменения их кода: логирование, кэширование, валидация, измерение времени выполнения.

## Простой декоратор

```python
def my_decorator(func):
    def wrapper():
        print("До вызова функции")
        result = func()
        print("После вызова функции")
        return result
    return wrapper

@my_decorator
def say_hello():
    print("Привет!")

say_hello()
# До вызова функции
# Привет!
# После вызова функции
```

## Декоратор с аргументами функции

```python
def log_calls(func):
    def wrapper(*args, **kwargs):
        print(f"Вызов функции {func.__name__} с аргументами: {args}, {kwargs}")
        result = func(*args, **kwargs)
        print(f"Функция {func.__name__} вернула: {result}")
        return result
    return wrapper

@log_calls
def add(a, b):
    return a + b

add(5, 3)
# Вызов функции add с аргументами: (5, 3), {}
# Функция add вернула: 8
```

## Декоратор с параметрами

```python
def repeat(times):
    """Декоратор, который повторяет вызов функции указанное количество раз"""
    def decorator(func):
        def wrapper(*args, **kwargs):
            results = []
            for _ in range(times):
                result = func(*args, **kwargs)
                results.append(result)
            return results
        return wrapper
    return decorator

@repeat(times=3)
def greet(name):
    print(f"Привет, {name}!")
    return f"Привет, {name}!"

greet("Иван")
# Привет, Иван!
# Привет, Иван!
# Привет, Иван!
```

## Сохранение метаданных функции

```python
from functools import wraps

def my_decorator(func):
    @wraps(func)  # Сохраняет метаданные оригинальной функции
    def wrapper(*args, **kwargs):
        """Обертка декоратора"""
        return func(*args, **kwargs)
    return wrapper

@my_decorator
def add(a, b):
    """Складывает два числа"""
    return a + b

print(add.__name__)  # add (а не wrapper)
print(add.__doc__)   # Складывает два числа
```

## Несколько декораторов

```python
def decorator1(func):
    def wrapper(*args, **kwargs):
        print("Декоратор 1: до")
        result = func(*args, **kwargs)
        print("Декоратор 1: после")
        return result
    return wrapper

def decorator2(func):
    def wrapper(*args, **kwargs):
        print("Декоратор 2: до")
        result = func(*args, **kwargs)
        print("Декоратор 2: после")
        return result
    return wrapper

@decorator1
@decorator2
def greet(name):
    print(f"Привет, {name}!")

greet("Иван")
# Декоратор 1: до
# Декоратор 2: до
# Привет, Иван!
# Декоратор 2: после
# Декоратор 1: после
```

## Практические примеры

### Декоратор для логирования
```python
def log(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        try:
            result = func(*args, **kwargs)
            print(f"{func.__name__} ok")
            return result
        except Exception as e:
            print(f"{func.__name__} error: {type(e).__name__}. {str(e)}")
            raise
    return wrapper

@log
def divide(a, b):
    return a / b
```

### Декоратор для измерения времени
```python
import time

def measure_time(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        end = time.time()
        print(f"{func.__name__} выполнилась за {end - start:.4f} секунд")
        return result
    return wrapper
```

## Приоритеты использования

### В первую очередь (важно знать)
- Базовые декораторы для расширения функциональности
- Декораторы с `*args, **kwargs` для универсальности
- `@wraps` для сохранения метаданных

### По необходимости
- Декораторы с параметрами
- Несколько декораторов на одной функции
- Класс-декораторы

## Примеры из проекта

В проекте декораторы используются для:
- Логирования выполнения функций (`@log` в `src/decorators.py`)
- Отслеживания успешных и неуспешных вызовов
- Обработки ошибок с логированием
