## Когда использовать

Функции используются **всегда** для организации кода, избежания дублирования и создания переиспользуемых блоков логики.

## Определение функции

```python
# Простая функция
def greet():
    print("Привет!")

# Функция с параметрами
def greet(name):
    print(f"Привет, {name}!")

# Функция с возвращаемым значением
def add(a, b):
    return a + b

result = add(5, 3)  # 8
```

## Параметры функции

### Позиционные параметры
```python
def multiply(x, y):
    return x * y

result = multiply(3, 4)  # 12
```

### Параметры по умолчанию
```python
def greet(name, greeting="Привет"):
    return f"{greeting}, {name}!"

greet("Иван")                    # "Привет, Иван!"
greet("Иван", "Здравствуй")      # "Здравствуй, Иван!"
```

### Именованные параметры
```python
def create_user(name, age, city="Москва"):
    return {"name": name, "age": age, "city": city}

# Можно вызывать с именованными параметрами
user = create_user(age=25, name="Иван")
```

## Возврат значений

```python
# Одно значение
def get_name():
    return "Иван"

# Несколько значений (возвращается кортеж)
def get_name_age():
    return "Иван", 25

name, age = get_name_age()  # Распаковка

# Ранний возврат
def check_positive(number):
    if number < 0:
        return False
    return True
```

## Область видимости

```python
# Глобальная переменная
count = 0

def increment():
    global count  # Объявление глобальной переменной
    count += 1

increment()
print(count)  # 1

# Локальная переменная
def local_example():
    local_var = 10
    return local_var

# local_var недоступна вне функции
```

## Документация функций

```python
def add(a, b):
    """
    Складывает два числа.
    
    Args:
        a: Первое число
        b: Второе число
    
    Returns:
        Сумма a и b
    """
    return a + b
```

## Приоритеты использования

### В первую очередь (обязательно знать)
- Определение функции (`def`)
- Параметры и возврат значений (`return`)
- Параметры по умолчанию
- Документация функций (docstrings)

### По необходимости
- Глобальные переменные (`global`)
- Вложенные функции
- Лямбда-функции (см. Продвинутые функции)
