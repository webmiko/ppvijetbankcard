## Когда использовать

Продвинутые возможности функций используются для создания гибкого и универсального кода, когда количество параметров неизвестно заранее или нужна дополнительная функциональность.

## *args - произвольное количество позиционных аргументов

```python
def sum_all(*args):
    """Суммирует все переданные аргументы"""
    total = 0
    for num in args:
        total += num
    return total

sum_all(1, 2, 3)        # 6
sum_all(1, 2, 3, 4, 5)  # 15
```

### Комбинация с обычными параметрами
```python
def greet(greeting, *names):
    for name in names:
        print(f"{greeting}, {name}!")

greet("Привет", "Иван", "Петр", "Мария")
# Привет, Иван!
# Привет, Петр!
# Привет, Мария!
```

## **kwargs - произвольное количество именованных аргументов

```python
def create_profile(**kwargs):
    """Создает профиль из переданных параметров"""
    profile = {}
    for key, value in kwargs.items():
        profile[key] = value
    return profile

user = create_profile(name="Иван", age=25, city="Москва")
# {'name': 'Иван', 'age': 25, 'city': 'Москва'}
```

### Комбинация *args и **kwargs
```python
def process_data(*args, **kwargs):
    print(f"Позиционные аргументы: {args}")
    print(f"Именованные аргументы: {kwargs}")

process_data(1, 2, 3, name="Иван", age=25)
# Позиционные аргументы: (1, 2, 3)
# Именованные аргументы: {'name': 'Иван', 'age': 25}
```

## Распаковка аргументов

```python
def multiply(x, y, z):
    return x * y * z

# Распаковка списка в позиционные аргументы
numbers = [2, 3, 4]
result = multiply(*numbers)  # 24

# Распаковка словаря в именованные аргументы
params = {'x': 2, 'y': 3, 'z': 4}
result = multiply(**params)  # 24
```

## Лямбда-функции

```python
# Обычная функция
def square(x):
    return x ** 2

# Лямбда-функция (анонимная функция)
square = lambda x: x ** 2

# Использование с map()
numbers = [1, 2, 3, 4]
squared = list(map(lambda x: x ** 2, numbers))  # [1, 4, 9, 16]

# Использование с filter()
evens = list(filter(lambda x: x % 2 == 0, numbers))  # [2, 4]

# Использование с sorted()
users = [{'name': 'Иван', 'age': 25}, {'name': 'Петр', 'age': 30}]
sorted_by_age = sorted(users, key=lambda u: u['age'])
```

## Функции высшего порядка

```python
def apply_operation(x, y, operation):
    """Применяет операцию к двум числам"""
    return operation(x, y)

def add(a, b):
    return a + b

def multiply(a, b):
    return a * b

result1 = apply_operation(5, 3, add)        # 8
result2 = apply_operation(5, 3, multiply)   # 15
```

## Замыкания (closures)

```python
def create_multiplier(n):
    """Создает функцию-умножитель на n"""
    def multiplier(x):
        return x * n
    return multiplier

double = create_multiplier(2)
triple = create_multiplier(3)

double(5)  # 10
triple(5)  # 15
```

## Приоритеты использования

### В первую очередь (важно знать)
- `*args` для произвольного количества аргументов
- `**kwargs` для произвольных именованных параметров
- Распаковка аргументов (`*`, `**`)

### По необходимости
- Лямбда-функции для простых операций
- Функции высшего порядка
- Замыкания для создания специализированных функций
