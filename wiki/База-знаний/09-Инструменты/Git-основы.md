## Когда использовать

Git используется при работе в команде, для версионирования кода и отслеживания изменений в проекте.

## Настройка Git

```bash
# Настройка имени и email
git config --global user.name "Ваше Имя"
git config --global user.email "your.email@example.com"

# Просмотр конфигурации
git config --list
```

## Базовые команды

### Инициализация репозитория
```bash
# Создание нового репозитория
git init

# Клонирование существующего репозитория
git clone <url>
```

### Проверка статуса
```bash
# Статус изменений
git status

# Краткий статус
git status -s
```

### Добавление файлов
```bash
# Добавить конкретный файл
git add file.py

# Добавить все изменения
git add .

# Добавить все файлы определенного типа
git add *.py
```

### Коммиты
```bash
# Создать коммит
git commit -m "Описание изменений"

# Добавить и закоммитить за один раз (только для отслеживаемых файлов)
git commit -am "Описание изменений"

# Изменить последний коммит
git commit --amend -m "Новое описание"
```

### Просмотр истории
```bash
# История коммитов
git log

# Краткая история
git log --oneline

# История с графиком веток
git log --oneline --graph --all

# История конкретного файла
git log file.py
```

## Работа с ветками

### Создание и переключение
```bash
# Создать новую ветку
git branch feature/new-feature

# Переключиться на ветку
git checkout feature/new-feature

# Создать и переключиться за один раз
git checkout -b feature/new-feature

# Просмотр всех веток
git branch

# Просмотр удаленных веток
git branch -r
```

### Слияние веток
```bash
# Переключиться на основную ветку
git checkout main

# Влить изменения из другой ветки
git merge feature/new-feature

# Удалить ветку после слияния
git branch -d feature/new-feature
```

## Работа с удаленным репозиторием

### Добавление удаленного репозитория
```bash
# Добавить удаленный репозиторий
git remote add origin <url>

# Просмотр удаленных репозиториев
git remote -v
```

### Отправка изменений
```bash
# Отправить изменения в удаленный репозиторий
git push origin main

# Отправить новую ветку
git push -u origin feature/new-feature
```

### Получение изменений
```bash
# Получить изменения из удаленного репозитория
git fetch origin

# Получить и влить изменения
git pull origin main
```

## Отмена изменений

### Отмена в рабочей директории
```bash
# Отменить изменения в файле (до добавления в staging)
git restore file.py

# Отменить все изменения
git restore .
```

### Отмена в staging area
```bash
# Убрать файл из staging area
git restore --staged file.py

# Убрать все файлы из staging area
git restore --staged .
```

### Отмена коммита
```bash
# Отменить последний коммит (сохранить изменения)
git reset --soft HEAD~1

# Отменить последний коммит (удалить изменения)
git reset --hard HEAD~1
```

## Приоритеты использования

### В первую очередь (по необходимости)
- `git init`, `git clone` - создание/клонирование репозитория
- `git add`, `git commit` - сохранение изменений
- `git status`, `git log` - просмотр статуса и истории
- `git push`, `git pull` - работа с удаленным репозиторием

### По необходимости
- Работа с ветками
- Отмена изменений
- Настройка `.gitignore`

## Примеры из проекта

В проекте Git используется для:
- Версионирования кода
- Работы с ветками (например, `feature/homework_12_2a`)
- Отслеживания изменений в файлах проекта
- Синхронизации с удаленным репозиторием
