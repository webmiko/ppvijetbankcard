# База знаний Python

База знаний создана на основе шпаргалок из папки `pre-code/dtbase`. Структурирована по областям применения с указанием приоритетов использования.

## 🎯 Приоритеты использования

- **Приоритет 1 (Обязательно)** - основы, без которых невозможно писать код
- **Приоритет 2 (Важно)** - необходимые инструменты для качественного кода
- **Приоритет 3 (По необходимости)** - продвинутые темы и инструменты

## 📚 Структура базы знаний

### 1. Основы Python (Приоритет 1)

Базовые концепции, которые нужно знать в первую очередь:

- [Строки](База-знаний/01-Основы/Строки.md) - работа со строками
- [Циклы](База-знаний/01-Основы/Циклы.md) - циклы for и while
- [Списки](База-знаний/02-Структуры-данных/Списки.md) - базовые коллекции данных

**Когда использовать:** Всегда, при написании любого кода.

---

### 2. Структуры данных (Приоритет 1)

Коллекции данных для хранения и обработки информации:

- [Списки](База-знаний/02-Структуры-данных/Списки.md) - упорядоченные коллекции
- [Словари](База-знаний/02-Структуры-данных/Словари.md) - пары ключ-значение
- [Множества, кортежи и вложенные коллекции](База-знаний/02-Структуры-данных/Множества-кортежи.md) - дополнительные типы коллекций

**Когда использовать:** При работе с данными любого типа.

---

### 3. Функции (Приоритет 1-2)

Организация кода в переиспользуемые блоки:

- [Базовые функции](База-знаний/03-Функции/Базовые-функции.md) - создание и использование функций
- [Продвинутые функции](База-знаний/03-Функции/Продвинутые-функции.md) - *args, **kwargs, lambda
- [Декораторы](База-знаний/03-Функции/Декораторы.md) - расширение функциональности функций

**Когда использовать:** 
- Базовые функции - всегда
- Продвинутые функции - при необходимости гибкости
- Декораторы - для логирования, кэширования, валидации

---

### 4. Генераторы и включения (Приоритет 2)

Эффективная работа с данными:

- [Включения и генераторы](База-знаний/04-Генераторы/Включения-генераторы.md) - list/dict/set comprehensions и генераторы

**Когда использовать:** 
- Включения - для создания коллекций из других коллекций
- Генераторы - для работы с большими объемами данных без загрузки в память

---

### 5. Модули и пакеты (Приоритет 2)

Организация кода в проектах:

- [Модули и пакеты](База-знаний/05-Модули/Модули-пакеты.md) - создание и импорт модулей

**Когда использовать:** При создании проектов с несколькими файлами.

---

### 6. Работа с данными (Приоритет 2-3)

Библиотеки для работы с различными форматами данных:

- [JSON, requests и datetime](База-знаний/06-Данные/JSON-requests-datetime.md) - работа с API и датами
- [CSV и pandas](База-знаний/06-Данные/CSV-pandas.md) - работа с табличными данными

**Когда использовать:**
- JSON, requests, datetime - при работе с API и обработке дат
- CSV, pandas - при анализе больших объемов табличных данных

---

### 7. Логирование (Приоритет 2)

Отслеживание работы программы:

- [Библиотека logging](База-знаний/07-Логирование/Logging.md) - настройка и использование логирования

**Когда использовать:** Для отладки и мониторинга работы приложения.

---

### 8. Тестирование (Приоритет 3)

Проверка корректности кода:

- [Тестирование с pytest](База-знаний/08-Тестирование/Pytest.md) - написание и запуск тестов

**Когда использовать:** Для обеспечения качества и надежности кода.

---

### 9. Инструменты разработки (Приоритет 3)

Инструменты для управления проектами и версиями:

- [Основы Git](База-знаний/09-Инструменты/Git-основы.md) - базовые команды Git
- [Продвинутый Git](База-знаний/09-Инструменты/Git-продвинутый.md) - ветвление, слияние, конфликты
- [Poetry. Оформление кода](База-знаний/09-Инструменты/Poetry-оформление.md) - управление зависимостями и форматирование

**Когда использовать:**
- Git - при работе в команде или для версионирования
- Poetry - для управления зависимостями в проектах

---

## 🗺️ Навигация по задачам

### Начинаю новый проект
1. Основы Python (строки, циклы)
2. Структуры данных (списки, словари)
3. Базовые функции
4. Модули и пакеты

### Работаю с данными
1. Структуры данных
2. JSON, requests, datetime
3. CSV, pandas (если нужен анализ таблиц)
4. Генераторы (для больших объемов)

### Нужна отладка
1. Логирование
2. Тестирование с pytest

### Работаю в команде
1. Git (основы)
2. Poetry (оформление кода)
3. Git (продвинутый)
