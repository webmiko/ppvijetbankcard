## 🎯 Принципы разработки

1. **База знаний - наивысший приоритет** - используем подходы из `wiki/База-знаний.md` в первую очередь
2. **Следование приоритетам** - Приоритет 1 → Приоритет 2 → Приоритет 3
3. **Сохранение стиля проекта** - если информации нет в базе знаний, действуем на свое усмотрение, но сохраняем стиль
4. **Не менять одобренный код** - никогда не изменяем ранее одобренный код без явного запроса

### ШАГ 4: Работа с данными

#### 4.1. Работа с JSON (Приоритет 2 - База знаний: JSON-requests-datetime)

```python
import json
from typing import Any, Dict, List
from pathlib import Path

# Константы
ENCODING = "utf-8"
DEFAULT_RETURN_VALUE: List[Dict[str, Any]] = []


def load_json_file(file_path: str) -> List[Dict[str, Any]]:
    """
    Загружает данные из JSON-файла.

    Args:
        file_path: Путь к JSON-файлу

    Returns:
        Список словарей с данными. Возвращает пустой список при ошибке.
    """
    logger.info(f"Загрузка данных из файла: {file_path}")
    
    try:
        # Проверка существования файла (Приоритет 1 - База знаний: Модули)
        if not Path(file_path).exists():
            logger.warning(f"Файл не найден: {file_path}")
            return DEFAULT_RETURN_VALUE
        
        # Чтение JSON (Приоритет 2 - База знаний: JSON-requests-datetime)
        with open(file_path, "r", encoding=ENCODING) as f:
            data = json.load(f)
        
        # Проверка типа (Приоритет 1 - База знаний: Структуры данных)
        if not isinstance(data, list):
            logger.warning("Файл содержит не список")
            return DEFAULT_RETURN_VALUE
        
        logger.info(f"Успешно загружено {len(data)} элементов")
        return data
        
    except json.JSONDecodeError as e:
        logger.error(f"Ошибка парсинга JSON: {e}")
        return DEFAULT_RETURN_VALUE
    except Exception as e:
        logger.error(f"Неожиданная ошибка: {e}")
        return DEFAULT_RETURN_VALUE
```

#### 4.2. Работа с датами (Приоритет 2 - База знаний: JSON-requests-datetime)

```python
from datetime import datetime

# Константы
DATE_FORMAT = "%d.%m.%Y"
DATETIME_FORMAT = "%Y-%m-%d %H:%M:%S"


def format_date(date_string: str) -> str:
    """
    Форматирует дату из ISO формата в читаемый вид.

    Args:
        date_string: Дата в формате ISO (например, "2024-03-15T14:30:00")

    Returns:
        Отформатированная дата (например, "15.03.2024")
    """
    try:
        # Парсинг даты (Приоритет 2 - База знаний: JSON-requests-datetime)
        dt = datetime.fromisoformat(date_string.replace("Z", "+00:00"))
        
        # Форматирование (Приоритет 2 - База знаний: JSON-requests-datetime)
        return dt.strftime(DATE_FORMAT)
        
    except ValueError as e:
        logger.error(f"Ошибка форматирования даты: {e}")
        return date_string
```

#### 4.3. Использование генераторов (Приоритет 2 - База знаний: Генераторы)

```python
from typing import Iterator, Dict, Any


def filter_items(items: List[Dict[str, Any]], condition: str) -> Iterator[Dict[str, Any]]:
    """
    Фильтрует элементы по условию (генератор).

    Args:
        items: Список элементов для фильтрации
        condition: Условие фильтрации

    Yields:
        Элементы, соответствующие условию
    """
    # Используем генератор для экономии памяти (Приоритет 2 - База знаний: Генераторы)
    for item in items:
        if item.get("status") == condition:
            yield item
```

#### 5.2. Использование логирования

```python
def process_data(data: List[Dict[str, Any]]) -> List[str]:
    """
    Обрабатывает данные с логированием.
    """
    # Логирование начала операции (Приоритет 2 - База знаний: Логирование)
    logger.info(f"Начало обработки: {len(data)} элементов")
    logger.debug(f"Данные: {data}")
    
    try:
        result = []
        
        for item in data:
            # Логирование важных шагов
            logger.debug(f"Обработка элемента: {item}")
            processed = process_item(item)
            result.append(processed)
        
        # Логирование успешного завершения
        logger.info(f"Обработка завершена: {len(result)} элементов")
        return result
        
    except Exception as e:
        # Логирование ошибок (Приоритет 2 - База знаний: Логирование)
        logger.error(f"Ошибка при обработке: {e}", exc_info=True)
        return []
```

**Уровни логирования:**
- `logger.debug()` - отладочная информация
- `logger.info()` - информационные сообщения
- `logger.warning()` - предупреждения
- `logger.error()` - ошибки

from typing import List, Dict, Any

def safe_operation(data: List[Dict[str, Any]]) -> List[Dict[str, Any]]:

    Безопасная операция с обработкой ошибок.

        # Основная логика

    except Exception as e:
        # Общий обработчик для неожиданных ошибок
