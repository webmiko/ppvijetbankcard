5. Лог должен перезаписываться при каждом запуске приложения
6. Типизировать код и добиться отсутствия ошибок mypy

ШАГ 2: Реализация функции настройки логеров
---------------------------------------------

2.1. Создать файл src/logger_config.py со следующей структурой:

    Импорты:
    - import logging
    - import os
    - from pathlib import Path
    - from typing import Optional

    Функция: setup_logger(module_name: str) -> logging.Logger
    Описание:
    - Принимает имя модуля (например, "masks" или "utils")
    - Создает и настраивает логер для этого модуля
    - Настраивает запись в файл с перезаписью при каждом запуске
    - Возвращает настроенный логер

    Логика:
    1. Создать путь к папке logs/ в корне проекта:
       - Определить корень проекта (можно использовать __file__)
       - Создать путь logs/{module_name}.log
    2. Создать папку logs/ если её нет (os.makedirs с exist_ok=True)
    3. Создать логер с именем модуля: logger = logging.getLogger(module_name)
    4. Установить уровень логирования (например, logging.INFO или logging.DEBUG)
    5. Очистить существующие обработчики логера (logger.handlers.clear())
    6. Создать FileHandler с режимом 'w' (перезапись):
       - handler = logging.FileHandler(log_file_path, mode='w', encoding='utf-8')
    7. Создать форматтер с нужным форматом:
       - Формат: "%(asctime)s - %(name)s - %(levelname)s - %(message)s"
       - Где:
         * %(asctime)s - метка времени
         * %(name)s - название модуля
         * %(levelname)s - уровень серьезности (INFO, ERROR, DEBUG, WARNING)
         * %(message)s - сообщение
    8. Установить форматтер для обработчика: handler.setFormatter(formatter)
    9. Добавить обработчик к логеру: logger.addHandler(handler)
    10. Вернуть логер

    Пример кода:
    def setup_logger(module_name: str) -> logging.Logger:
        # Определяем корень проекта
        project_root = Path(__file__).parent.parent
        logs_dir = project_root / "logs"
        logs_dir.mkdir(exist_ok=True)
        
        log_file = logs_dir / f"{module_name}.log"
        
        logger = logging.getLogger(module_name)
        logger.setLevel(logging.INFO)
        logger.handlers.clear()
        
        handler = logging.FileHandler(log_file, mode='w', encoding='utf-8')
        formatter = logging.Formatter(
            '%(asctime)s - %(name)s - %(levelname)s - %(message)s',
            datefmt='%Y-%m-%d %H:%M:%S'
        )
        handler.setFormatter(formatter)
        logger.addHandler(handler)
        
        return logger

        logger.debug(f"Чтение содержимого файла: {file_path}")

        logger.warning(f"Файл пустой: {file_path}")

        logger.debug(f"Парсинг JSON из файла: {file_path}")
      * Если данные не являются списком:
        logger.warning(f"Данные в файле не являются списком: {file_path}")
      * При успешной загрузке:

      * При обработке исключений:
        logger.error(f"Ошибка при загрузке транзакций из файла {file_path}: {error_message}", exc_info=True)
